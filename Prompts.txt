## Grammar + ANTLR

1. How do I add new token types like BYTE_SIZE and TIME_DURATION to an ANTLR4 grammar for a DSL?
2. What’s the best way to define units like KB, MB, ms, and s in ANTLR lexer rules with fragments?
3. How do I make ANTLR accept values like '1.5MB' or '200ms' as valid arguments in directive syntax?
4. After modifying Directives.g4, how do I regenerate the Java parser and lexer classes in a Maven project?

## Token Parsing (Java)

5. How do I write a Java class that parses strings like "1.5MB" into bytes? How to deal with units and decimal points?
6. What’s the cleanest way to convert a time duration like “2.1s” into milliseconds or nanoseconds in Java?
7. Show me a Java class that extends a base Token class and implements parsing logic for byte sizes.
8. What’s the difference between binary (1024-based) and decimal (1000-based) byte conversions, and which should I use?

11. What’s the correct way to store and retrieve custom tokens like ByteSize or TimeDuration in a TokenGroup?

## Aggregate Directive Logic

15. What’s a good way to structure the define() method to accept multiple column names and optional unit arguments?
